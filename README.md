# 💫 About Me

👋 Hi, I'm Alejandro — a full-stack developer and co-founder of Ollidevs, a development studio focused on building scalable web applications, automation systems, and modern digital experiences.

I specialize in Next.js, React, TypeScript, Tailwind CSS, Laravel, and backend development, creating solutions that combine performance, scalability, and clean user experiences.

### 💡 My interests include:

• Full-stack web development
• SaaS and startup products
• Automation and AI integrations
• UX/UI optimization
• Productivity systems and scalable workflows
• Modern software architecture

🚀 Currently, I'm focused on:

• Growing Ollidevs
• Building custom software solutions for clients
• Developing productivity and wellness applications
• Expanding my iOS development skills with SwiftUI
• Exploring AI-powered tools and automations
